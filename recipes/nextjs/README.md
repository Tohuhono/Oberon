# OberonCMS: Next.js recipe

This recipe supplies the Next.js app structure for `create-oberon-app`. The installer configures
your database, email service, and initial admin.

See [Getting started](https://oberoncms.com/docs/create-oberon-app) to create an app. See
[Configuration](https://oberoncms.com/docs/configuration) to change it. Use the
[deployment guide](https://oberoncms.com/docs/deployment) for production setup.
