# Next.js Playground

This app tests OberonCMS integration with Next.js. It uses PostgreSQL, development email, and
dynamic Tailwind styles. It also configures Resend for production email.

Run `pnpm dev:oberon` from the repository root. The development URL is `http://localhost:3210`. See
the [contributor guide](../../README.md) for setup and validation. See
[Configuration](https://oberoncms.com/docs/configuration) for runtime setup.
