# TanStack Playground

This app tests OberonCMS integration with TanStack Start. It uses PostgreSQL, development email, and
dynamic Tailwind styles. It also configures Resend for production email.

Run `pnpm dev:new` from the repository root. The default development URL is `http://localhost:5173`.
See the [contributor guide](../../README.md) for setup and validation. See
[Configuration](https://oberoncms.com/docs/configuration) for runtime setup.
