# Introduction

<Callout type="info">
  Use [create-oberon-app](/docs/create-oberon-app) to create a starter app.
</Callout>

OberonCMS is a content management system for Next.js and TanStack Start. It uses the
[Puck visual editor](https://puckeditor.com) to build pages. Plugins supply database, email,
storage, and framework behavior.
