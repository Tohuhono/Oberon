# Turso

The plugin stores CMS data and auth records in a Turso database.

## Setup

Install the plugin:

```sh npm2yarn
npm install @oberoncms/plugin-turso
```

Import it in `oberon/config.ts`:

```tsx
import { plugin as databasePlugin } from "@oberoncms/plugin-turso"
```

Add `databasePlugin` after the development plugin. See [Configuration](/docs/configuration) for the
plugin list.

## Environment variables

Create a database with [Turso](https://docs.turso.tech/). Set its URL and token:

```sh
TURSO_URL=libsql://your-database.turso.io
TURSO_TOKEN=your-token
USE_DEVELOPMENT_DATABASE=false
```

When `USE_DEVELOPMENT_DATABASE` is true, this plugin is disabled. Use the
[development plugin](/docs/plugins/development) for local storage. Bootstrap runs the enabled
database plugin's migrations.
