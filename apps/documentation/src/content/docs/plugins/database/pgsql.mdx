# PostgreSQL

The plugin stores CMS data and auth records in PostgreSQL.

## Setup

Install the plugin:

```sh npm2yarn
npm install @oberoncms/plugin-pgsql
```

Import it in `oberon/config.ts`:

```tsx
import { plugin as databasePlugin } from "@oberoncms/plugin-pgsql"
```

Add `databasePlugin` after the development plugin. See [Configuration](/docs/configuration) for the
plugin list.

## Environment variables

Set the connection URL:

```sh
DATABASE_URL=postgresql://user:password@host:5432/database
USE_DEVELOPMENT_DATABASE=false
```

Use the connection options required by your database host. When `USE_DEVELOPMENT_DATABASE` is true,
this plugin is disabled. Use the [development plugin](/docs/plugins/development) for local storage.
Bootstrap runs the enabled database plugin's migrations.
