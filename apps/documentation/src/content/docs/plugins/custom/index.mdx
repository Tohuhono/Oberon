# Custom plugins

Use a custom plugin when the built-in providers do not meet your requirements. Add it to
`oberon/config.ts` as shown in [Configuration](/docs/configuration).

Start with [Plugin shape](/docs/plugins/custom/plugin-shape). Use
[Adapter hooks](/docs/plugins/custom/adapter-hooks) to add or wrap CMS methods. Use
[Handler hooks](/docs/plugins/custom/handler-hooks) to add HTTP endpoints.
