# Development plugin

The plugin provides a local SQLite database and logs sign-in codes instead of sending email.

## Setup

Install the plugin:

```sh npm2yarn
npm install @oberoncms/plugin-development
```

Import it in `oberon/config.ts`:

```tsx
import { plugin as developmentPlugin } from "@oberoncms/plugin-development"
```

Put it first in the plugin list. Keep your production database and send plugins in that list. See
[Configuration](/docs/configuration) for the complete setup.

## Feature flags

Use these variables to select development behavior:

```sh
USE_DEVELOPMENT_DATABASE=true
USE_DEVELOPMENT_SEND=true
```

Each flag accepts `true` or `false`. Without an explicit value, development behavior is enabled
outside CI when `NODE_ENV` is unset or `development`. The plugin is disabled when both features are
off.

Set both flags to `false` in production. Generated apps explicitly set them to `true` in
`.env.local`, including when you build locally. See [Deployment](/docs/deployment) before you build
for production.
