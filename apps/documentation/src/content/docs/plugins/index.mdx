# Plugins

Plugins add database, email, storage, authentication, and framework behavior. Add them to the
ordered list in `oberon/config.ts`. See [Configuration](/docs/configuration) for setup and plugin
order.

## Available plugins

- [Database](/docs/plugins/database): Turso and PostgreSQL
- [Email](/docs/plugins/send): Resend, SendGrid, and custom templates
- [Storage](/docs/plugins/storage): Flydrive and Uploadthing
- [Authentication](/docs/plugins/auth): Email codes and sessions
- [Development](/docs/plugins/development): Local database and logged sign-in codes
- [Tailwind](/docs/plugins/tailwind): CSS from published page data

The framework plugins provide Next.js or TanStack Start integration. See
[HTTP handlers](/docs/plugins/custom/handler-hooks) for route setup.

## Custom plugins

Start with [Plugin shape](/docs/plugins/custom/plugin-shape). Use
[Adapter hooks](/docs/plugins/custom/adapter-hooks) for CMS behavior. Use
[Handler hooks](/docs/plugins/custom/handler-hooks) for HTTP endpoints.
