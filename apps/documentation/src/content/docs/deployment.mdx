# Deployment

OberonCMS supports Next.js and TanStack Start. Use a host that supports your framework and Node.js
24.21.0 or later. For platform setup, use the framework's deployment guide:

- [Next.js](https://nextjs.org/docs/app/getting-started/deploying)
- [TanStack Start](https://tanstack.com/start/latest/docs/framework/react/guide/hosting)

## Prepare the app

1. Configure your production database.
2. Configure your email service.
3. Set the [auth variables](/docs/plugins/auth).
4. Set the credentials for your [selected plugins](/docs/plugins).
5. Set `USE_DEVELOPMENT_DATABASE=false`.
6. Set `USE_DEVELOPMENT_SEND=false`.
7. Set `BETTER_AUTH_URL` to your public HTTPS URL.

The installer enables development features in `.env.local`. Do not use those settings for production
builds. The build process must use the intended production database.

## Build

Run the generated app's build script:

```sh npm2yarn
npm run build
```

The app's `prebuild` script runs [Oberon bootstrap](/docs/configuration#bootstrap). Bootstrap runs
database migrations and creates initial CMS data. Give the build environment access to the required
database and email settings.

Use your framework's deployment guide to run the build output. The TanStack recipe's preview command
is for checking a build, not a production hosting guide.

## Check the deployment

1. Open `/cms` on the deployed site.
2. Sign in with an existing admin email.
3. Create a test page.
4. Publish the page.
5. Open the published page.
6. Test image uploads if you configured storage.

Use HTTPS for the public site and editor. Keep database, email, storage, and auth secrets out of
browser code. Check host logs if a build or request fails. See
[Troubleshooting](/docs/troubleshooting) for CMS-specific checks.
